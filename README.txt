Assyrian Aid Relief Australia - website files
==============================================

Upload EVERYTHING inside this folder (not the folder itself) to the root of
your hosting site. Keep the sub-folders exactly as they are.

  index.html       the website (the hosting site opens this automatically)
  images/          AARA logo, partner + ACNC logos, sponsor logos
  team/            committee headshots
  events/          Christmas Brunch flyer
  projects/        project photos and videos (one folder per project)
  .nojekyll        needed for GitHub Pages - leave it in

GitHub Pages
------------
1. github.com > New repository > name it (e.g. assyrian-aid-relief) > Public > Create.
2. Click "uploading an existing file", drag in everything from this folder,
   then "Commit changes". (If .nojekyll is hidden on your computer, create it
   on GitHub with "Add file > Create new file", name it .nojekyll, leave it empty.)
3. Settings > Pages > Branch: main, folder: / (root) > Save.
4. After 1-2 minutes the site is live at https://<username>.github.io/<repo-name>/
5. Custom domain: Settings > Pages > Custom domain > AssyrianAidRelief.org,
   then add the DNS records GitHub shows you at your domain registrar.

To update a photo later, upload a file with the same name into the same folder.
